# Privacy

PSO's API serves analytics counted over all games together, plus released match history and player records with the same privacy as public PSO profiles: when a player's replay of a game is private, only their name, Avatar and result are shown. There are no replay downloads. The only replay in this repo, `fixtures/replays/replay_example.json`, is made up.

Don't try to work out what a private game hides, such as a private player's deck or colors.

If you find anything personal in this repo, tell the PSO team on the PSO Discord.
